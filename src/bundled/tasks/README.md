# Tasks

A task holds the context for a piece of work and links the conversations about it, so anyone can pick it up later.

## Getting started

1. Open **Tasks** and choose **New task**, give it a title and a description, and add images if they help.
2. In a chat or channel, choose **Tasks** in its header to see the tasks linked there, make one from the chat, or link the chat to an existing task.

You can also ask your agent to make a task from a conversation.

- Everyone in the community can see and edit every task.
- Linking a private Solo chat makes it View only: anyone in the community can read it, and only its members can post. You confirm that first. Unlinking doesn't change it back.
- Linking a private channel doesn't change who can read it. People who can't read it see only that a private channel is linked.
- If someone else saves a task while you're editing it, your text is kept and you choose what to save.
